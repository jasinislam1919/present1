# Stargazer Lily & Heart Particle Project

GitHub Pages-ready Three.js project.

## Deploy
1. Upload `index.html` and the `js/` folder to the repository root.
2. In GitHub: Settings → Pages → Deploy from a branch → choose `main` and `/ (root)`.
3. Open the published Pages URL.

Three.js and addons load from jsDelivr via the import map in `index.html`; no build step is required.
